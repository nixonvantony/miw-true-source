# WATCH REGISTER

Package: general-average · as_at: 2026-08-16

| # | Item | Watch |
|---|---|---|
| W1 | YAR version | Current edition = YAR 2016, and it remains YAR 2016 — the maintained text carries the Genoa (September 2016, Rule XVII) and Antwerp (October 2022, Rule XXI(b)) corrections without any renumbering. **An edition-year check will therefore never detect an in-edition amendment**, which is how the Rule XXI change went unnoticed here until 2026-08-16. Watch for further CMI corrections as well as for a new edition; many contracts still incorporate YAR 1994/1974 — updated 2026-08-16 |
| W2 | Rule Paramount | A reasonableness gate: it admits nothing unless the sacrifice or expenditure was reasonably made or incurred. Watch case law on what that reasonableness standard requires. **It is not a fault gate** — corrected 2026-08-15, TSCR-6 |
| W3 | Official text capture | CMI official YAR 2016 text verified 2026-08-15 for the Rule Paramount, Rule D and **Rule VI** only (see `YAR_SOURCE_PROVENANCE.md`). **The remaining definition objects have not been checked against it, and two are known to carry pre-2016 content** — see the residual defects in that file. The public-derived migration did **not** change this: three objects are `primary_verified` and three are `unverified_legacy`, exactly as before |
| W5 | Private evidence availability | The verbatim evidence behind the verified objects now lives outside this repository, addressed by `evidence_id` and `private_location_key` — see `PRIVATE_EVIDENCE_BOUNDARY.md`. Watch that the vault stays available and that its `evidence_sha256` values continue to match `EVIDENCE_INDEX.json`. A mismatch is investigated, never reconciled by editing a hash — added 2026-08-15, YAR public-derived migration |
| W4 | Edition of the incorporated Rules | The salvage treatment under Rule VI has moved **twice**: allowed under YAR 1994, removed by YAR 2004, restored subject to qualifications by YAR 2016. Any statement about salvage in GA is edition-dependent and must name its edition. Watch for contracts still incorporating 1994 or 2004 — added 2026-08-15, TSCR-9 |
| W6 | Rule XXI(b) benchmark | The **rule** is fixed (USD Prime Rate + 2 per cent per annum); the **rate value** changes every calendar year, being taken from the Wall Street Journal on the first banking day of that year. Never hard-code a numeric interest rate into this corpus — hold the formula only. Watch for any withdrawal or redefinition of the USD Prime Rate: benchmark withdrawal is exactly what forced the October 2022 amendment, so it is a known failure mode of this paragraph, not a hypothetical one — added 2026-08-16 |
| W8 | Reproduction status is not yet modelled | The current objects record *what the source says* and *where the evidence is*, but nothing records *whether that source may be reproduced publicly* — the derived-only posture is implied by policy rather than carried as data. This is an **observation, not a defect**: the model is already source-traceable (`source_id`, `source_sha256`, `locator`, `evidence_id`), so a future field such as `source_text_publication_status` (`derived_only` / `short_quote_permitted` / `reproduction_authorised` / `public_domain` / `licence_restricted`) could be added without restructuring anything. **Do not read the present public-derived posture as a permanent rule that verbatim source text can never be published**: where MIW holds the reproduction right, a consolidated third-party edition may legitimately carry much more source wording. No field was added on 2026-08-16 — upstream convention does not yet support one, and inventing it unilaterally would be schema drift — added 2026-08-16 |
| W7 | Which CMI posting is current | CMI publishes two postings of the 2016 Rules. **Neither filename nor file date orders them**: the maintained text sits at the plainer filename (`YAR-2016-English-Version.pdf`, PDF created 2023-01-26) while the superseded posting has the more specific-looking name and a **later** PDF creation date (2024-08-06). Identify the maintained text by the CMI page labels and by reading Rule XXI(b) — LIBOR means the superseded posting, USD Prime Rate means the maintained one. Sources registered as `CMI-YAR-2016` and `CMI-YAR-2016-PRE-2022` — added 2026-08-16 |
